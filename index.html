От идеи до бота за 4 шага

Без установки, без регистрации, без кредитной карты.

Соберите сценарий

Перетащите блоки на холст и соедините их рёбрами. Превью чата показывает сценарий в реальном времени.

Проверьте и экспортируйте

Редактор проверит сценарий и отдаст файл конфигурации — кнопкой «Проверить и экспорт».

Сгенерируйте проект

Одна команда CLI разворачивает готовый проект: npx umbot create from-flow flow.json

Запустите бота

Укажите токены платформ в .env, npm install — и бот отвечает пользователям. Код открыт: меняйте что угодно.

Вы не заперты в редакторе

На выходе — не «чёрный ящик», а нормальный TypeScript-проект на фреймворке umbot. Его можно дописывать, версионировать в git и отдавать команде разработчиков.

  • Человекочитаемый JSON-формат сценария — документирован и стабилен
  • Сгенерированный код можно редактировать напрямую
  • Конфигурацию можно загрузить обратно в редактор и править визуально
  • Данные и токены остаются у вас — редактор никуда их не отправляет

Частые вопросы

Это бесплатно?
Да, Umbot Flow Editor полностью бесплатен и open-source. Редактор работает в браузере, генератор проекта доступен через npm. Никаких скрытых платежей и подписок.
Нужен ли свой сервер?
Редактор работает в браузере — сервер не нужен. Для запуска сгенерированного бота нужен компьютер с Node.js 18+. Бот будет работать на вашем сервере, данные хранятся локально.
Какие платформы поддерживаются?
Поддерживаются: Алиса (Яндекс), Telegram, VK, Маруся (Сбер), Max (VK), Viber, SmartApp (Сбер). Можно выбрать одну или несколько платформ одновременно.
Сложно ли запустить бота после скачивания?
Нет. Скачиваете файл конфигурации, устанавливаете Node.js и выполняете одну команду. Готовый проект с кодом появится автоматически. Если не знаете что делать с кодом — отправьте его разработчику.
Что такое umbot?
Umbot — это фреймворк для создания мультиплатформенных чат-ботов. Поддерживает Алису, Telegram, VK, Марусю и другие платформы. Визуальный редактор создаёт конфигурацию, а специальная программа генерирует готовый проект.
Можно ли редактировать конфигурацию вручную?
Да, формат полностью документирован. Можно редактировать в любом текстовом редакторе и загружать обратно в визуальный редактор. Формат стабилен — обновления не ломают ранее созданные конфигурации.
