Documentation

Everything you need to work with Umbot Flow

Umbot Flow is a visual chatbot builder: you assemble the scenario with blocks on a canvas, the editor validates it and turns it into a ready TypeScript project for Telegram, Alisa, VK and other platforms. Four sections below: start with the quick start guide and keep the references handy.

Quick Start

A step-by-step guide with examples and screenshots: from the first block on the canvas to a running bot — in about 15 minutes.

Block Types

A detailed description of every block type: commands with trigger words, input steps, conditions, actions, responses and end. With setup examples.

JSON Format

The flow.json reference: document structure, all node and edge types, condition operators and variable substitution. For editing the config by hand.

FAQ

Answers to common questions: pricing and license, platform support, launching the generated bot on your own server.
