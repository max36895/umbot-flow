JSON Configuration Format

Full specification of the format generated by the visual editor

Tip: The complete specification with code examples is available in the GitHub repository.

Document structure

{
    "schemaVersion": "1.0",
    "name": "my-bot",
    "version": "1.0.0",
    "platforms": ["telegram", "alisa"],
    "database": { "type": "file", "config": {} },
    "nodes": [],
    "edges": [],
    "fallback": { "text": "Sorry, I didn't understand." },
    "welcome": { "text": "Hello!" }
}

Node types

Type Description
command Command — reacts to trigger words
step Step — asks for input and saves it
condition Condition — branching by variable
action Action — HTTP requests, variables, numbers
response Response — shows text and buttons
end End — closes the dialog

Edges

Type Description
next Sequential transition to the next block
branch_true The "yes" branch from a condition
branch_false The "no" branch from a condition

Variable substitution

Use {{name}} in text — the value is substituted automatically. 

"Hello, {{userName}}!"  →  setText(ctrl, `Hello, ${ctrl.userData.userName}!`)
