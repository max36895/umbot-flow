Quick Start

From opening the editor to a running bot in 15 minutes

1

Open the editor

Go to the home page and start building your bot. Drag a "Command" block onto the canvas.

2

Configure the bot

Click the block and fill in the trigger words (words the bot reacts to) and the response text. Add buttons, conditions and other blocks as needed.

3

Export the configuration

Click "Validate & Export" in the top toolbar. Download the flow.json file.

4

Install Node.js

If you don't have Node.js yet, download and install version 18 or higher from nodejs.org.

5

Generate the project

Open a terminal in the folder with flow.json and run:

npx umbot create from-flow flow.json --output ./my-bot

A ready-to-run project with code will appear in the my-bot folder.

Not sure what to do with the code? Send the my-bot folder to your developer — they will launch the bot for you.
6

Launch the bot

Open the my-bot folder and follow the instructions in its README.
