Типы блоков

Подробное описание каждого типа блока в редакторе

Команда

Реагирует на определённые слова. Пользователь вводит слово — бот отвечает настроенным текстом и кнопками.

Пример: Блок "Команда" со словами "привет", "здравствуй" и текстом "Привет! Как дела?" — бот ответит при вводе любого из этих слов.

Шаг

Запрашивает ввод у пользователя и сохраняет его в поле. Используйте для сбора данных: имя, email, возраст и т.д.

Пример: Блок "Шаг" с текстом "Как вас зовут?" и настройкой "Сохранить в" = "userName" — ответ пользователя сохранится в поле userName.

Условие

Проверяет значение переменной и ведёт диалог по разным веткам. Позволяет создавать ветвления: "если условие выполнено — идти туда, иначе — сюда".

Пример: Если возраст >= 18 — показать одно сообщение, иначе — другое.

Действие

Выполняет дополнительные действия: установка переменных, генерация случайных чисел, HTTP-запросы. Показывает текст после выполнения.

Пример: Генерация случайного числа от 1 до 100, отправка HTTP-запроса к API, установка переменной.

Ответ

Показывает текст пользователю без запроса ввода. Используйте для информационных сообщений или как промежуточный блок.

Пример: Блок "Ответ" с текстом "Это справка по боту" — просто покажет сообщение.

Завершение

Завершает диалог. Бот перестаёт отвечать, пока пользователь не начнёт новый разговор.

Пример: После сообщения "До свидания!" диалог завершается.

Служебные блоки

Эти блоки не соединяются с другими — каждый из них существует в единственном экземпляре и срабатывает в определённый момент.

Старт

Приветствие при запуске бота. Показывается пользователю, когда он впервые открывает диалог или начинает новый разговор.

Пример: Текст "Привет! Я помогу вам с заказом. Напишите 'помощь', если что-то непонятно."

Помощь

Ответ на команду помощи. Срабатывает, когда пользователь запрашивает справку (например, пишет "помощь" или нажимает кнопку помощи платформы).

Пример: Текст "Я умею отвечать на команды 'заказ' и 'статус'. Напишите одно из этих слов."

Ответ по умолчанию

Ответ, когда бот не распознал команду пользователя. Вместо молчания или системной ошибки пользователь получит понятное сообщение.

Пример: Текст "Извините, я вас не понял. Напишите 'помощь', чтобы увидеть список команд."

Как соединять блоки

Перетаскивайте от края одного блока к другому, чтобы создать связь. Бот будет двигаться по блокам в порядке соединений. Используйте условие для ветвления: один выход для "да", другой для "нет".
