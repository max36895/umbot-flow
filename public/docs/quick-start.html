Быстрый старт

От открытия редактора до работающего бота за 15 минут — без регистрации

1

Откройте редактор

На главной странице нажмите «Открыть редактор». Редактор работает прямо в браузере: слева — палитра блоков, в центре — холст, сверху — панель инструментов. Проект автоматически сохраняется, файл конфигурации можно забрать в любой момент.

2

Поставьте блок команды

Перетащите блок «Команда» из палитры на холст. Команда — это реакция на слова пользователя: он пишет «привет», бот отвечает настроенным текстом. Демо-блоки, которые уже стоят на холсте, можно удалить — выделите блок и нажмите Delete — или собрать свой сценарий рядом с ними.

3

Настройте триггеры и ответ

Нажмите на блок — откроется панель свойств. Заполните слова-триггеры («привет», «здравствуй») и текст ответа («Привет! Я бот книжного магазина. Как вас зовут?»). У каждого поля есть подсказка, которая объясняет значение.

4

Сохраните ответ пользователя в переменную

Добавьте блок «Шаг» и протяните связь от первого блока ко второму. В шаге напишите вопрос «Как вас зовут?» и укажите «Сохранить в: userName» — ответ пользователя сохранится в переменную. Подставьте её в любой следующий текст через {{userName}}, а блок «Условие» проверит значение и поведёт диалог по одной из двух ветвей.

5

Проверьте сценарий в превью

Нажмите «Предпросмотр чата» на верхней панели и напишите «привет». Превью проигрывает сценарий так же, как это сделает платформа: показывает приветствие, реагирует на слова-триггеры, сохраняет переменные. Ошибки подсвечиваются прямо на блоках — вы увидите проблему до запуска бота.

6

Экспортируйте конфигурацию

Нажмите «Проверить и экспортировать». Редактор проверит сценарий (пустые ответы, потерянные блоки, дубли имён) и предложит скачать файл flow.json — это весь ваш бот в одном файле. Его можно править вручную и загружать обратно в редактор.

Не хотите разбираться с кодом? Файл flow.json — законченная постановка задачи: передайте его разработчику, и он запустит бота за вас.
7

Установите Node.js

Для запуска бота нужен Node.js версии 18 или новее — скачайте его с nodejs.org. Если Node.js уже установлен, проверьте версию командой node -v.

8

Сгенерируйте проект

Откройте терминал в папке с файлом flow.json и выполните:

npx umbot create from-flow flow.json --output ./my-bot

Команда создаст готовый TypeScript-проект: исходный код бота (src/index.ts, src/utils.ts), package.json и tsconfig.json.

9

Запустите бота

Установите зависимости, соберите проект и запустите бота:

cd my-bot
npm install
npm run build
npm start

Бот поднимется на localhost:3000. Платформы (Telegram, Алиса, VK, Маруся и другие) подключаются адаптерами в src/index.ts — токены вы задаёте на своей стороне.
