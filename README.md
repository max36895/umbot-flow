# Umbot Flow Editor

Визуальный редактор для создания чат-ботов на базе фреймворка [umbot](https://www.npmjs.com/package/umbot). Бот собирается из блоков на холсте: команды, шаги, условия, действия и ответы соединяются рёбрами, а редактор генерирует JSON-конфигурацию, из которой CLI разворачивает готовый TypeScript-проект бота.

## Возможности

- **Визуальный холст** на React Flow: drag-and-drop блоков, соединения, миникарта, снап к сетке, мультивыделение и групповое удаление (Shift+клик + Delete).
- **7 типов блоков**: Command (реакция на слова-триггеры), Step (запрос ввода с сохранением в переменную), Condition (ветвление по переменной), Action (установка переменных, случайные числа, HTTP-запросы), Response (показ текста), Start/End, а также служебные Welcome / Help / Fallback.
- **Панель свойств** (закрепляемая или плавающая) с подсказками, пресетами переменных, редакторами кнопок и карточек (single/list/gallery).
- **Превью чата** — симуляция бота прямо в редакторе: срабатывание команд, шаги, условия, переменные, имитация HTTP-запросов, панель отладки переменных.
- **Валидация** на двух уровнях: JSON Schema (AJV) + графовые проверки (дубли имён, висячие рёбра, незаполненные условия, осиротевшие блоки). Ошибки подсвечиваются на блоках, в панели свойств и в статус-баре.
- **Экспорт**: `flow.json` (копирование/скачивание) и PNG-снимок холста.
- **Undo/Redo** (Ctrl+Z / Ctrl+Shift+Z) со схлопыванием быстрого ввода текста в один шаг истории.
- **Автосохранение** в localStorage + список недавних проектов.
- **Горячие клавиши**: Ctrl+K — палитра команд, Ctrl+N — новый проект, Ctrl+C/X/V — копирование блоков, Ctrl+D — дублирование, Ctrl+E — экспорт.
- **Локализация**: русский и английский, переключение без перезагрузки интерфейса.

## Запуск

```bash
npm install
npm run dev        # dev-сервер на http://localhost:3001
```

## Сборка и проверки

```bash
npm run build      # tsc + vite build (в dist/)
npm run test       # vitest: 178 тестов (утилиты, сторы, компоненты)
npm run lint       # eslint (flat config)
npm run prettier   # форматирование
```

## Как запустить собранного бота

1. Соберите флоу в редакторе и нажмите «Проверить и экспорт» — скачается `flow.json`.
2. Выполните:

```bash
npx umbot create from-flow flow.json --output ./my-bot
```

3. Откройте папку `my-bot` и следуйте инструкциям в её README.

## Технологии

| Слой       | Технология                          |
| ---------- | ----------------------------------- |
| UI         | React 18 + TypeScript (strict)      |
| Холст      | React Flow 12 (@xyflow/react)       |
| Состояние  | Zustand                             |
| Стили      | Tailwind CSS                        |
| Сборка     | Vite (vendor-чанки: react, xyflow, ajv) |
| Валидация  | AJV + JSON Schema                   |
| Тесты      | Vitest + Testing Library (jsdom)    |
| Линтер     | ESLint 9 (flat config) + Prettier   |

## Формат flow.json

Документ описывает бота декларативно:

```json
{
    "schemaVersion": "1.0",
    "name": "my-bot",
    "version": "1.0.0",
    "platforms": ["telegram"],
    "nodes": [
        { "type": "command", "id": "greet", "name": "greet", "slots": ["привет"], "response": { "text": "Привет!" } },
        { "type": "end", "id": "end_1" }
    ],
    "edges": [{ "from": "greet", "to": "end_1", "type": "next" }],
    "welcome": { "text": "Здравствуйте!" },
    "fallback": { "text": "Не понял запрос." }
}
```

Типы рёбер: `next`, `branch_true`, `branch_false`. Полная схема — в `src/schemas/flow.schema.json`.
